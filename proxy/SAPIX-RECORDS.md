# SAPIX 採点記録の端末間同期

`sapix/sapix_sansu_trainer.html` の「Googleで接続」から、各端末で同じ管理者の Google アカウントに接続します。既存の端末内記録は初回の同期で取り込まれ、以降は採点・訂正・取り消しを自動で同期します。採点記録を GitHub の公開ファイルへ保存することはありません。

通信できない間も端末に記録を保存します。「同期待ち」はまだ別端末へ届いていない状態です。通信復帰時やページを開き直したときに再試行し、「今すぐ同期」でも確認できます。初めて使う端末ではオンラインで接続してください。ブラウザのデータを消す前には同期の完了を確認するか、記録を書き出してください。

## 認証と保存先

- 認証に使うアカウントは既存の `STUDIO_OWNER_EMAIL` です。第三者の Google アカウントは拒否します。
- Google ログインには本人確認用の `openid email` だけを使い、教材生成の Drive 接続とは分離します。既存の管理者セッションがあれば再利用します。
- ページの移動によるログインと PKCE を使います。iPhone のサードパーティ Cookie 許可は不要です。
- 戻り先は既存の SAPIX トレーナー URL に固定します。有効期間の短い一度限りのコードを採点専用の端末トークンへ交換します。Google、GitHub、OpenAI のトークンをページへ渡しません。
- 端末トークンの有効期間は90日です。ブラウザ内に保持され、「接続を解除」でその端末のトークンを失効させます。他端末の接続は維持します。
- Cloudflare の既存 `StudioState` Durable Object に採点専用のキーで保存します。教材生成ジョブや Drive 認証情報は変更しません。API の許可 Origin は `ALLOWED_ORIGIN` に限定します。

## 同期時の扱い

記録ごとにIDを付け、追加・訂正・削除を送信します。全件を別端末の内容で上書きしません。再送しても同じ記録が重複せず、削除済みIDを保持することで古い端末が記録を復活させることを防ぎます。全消去はその端末が確認済みの記録を削除し、別端末で同時に追加された未確認の記録は残します。

従来の記録は、問題・日付・採点・時間・同一記録の出現順から決まるIDで取り込みます。同じバックアップを複数端末で取り込んだ場合の重複を防ぎながら、同じ日に同じ点で複数回解いた履歴も保持します。端末内の同期用データには記録と未送信の操作をまとめて保存し、書き込みに失敗した場合は成功表示しません。

## API

- `GET /api/sapix/auth/start?challenge=...&state=...`: Google ログイン開始。
- `POST /api/sapix/auth/exchange`: 一度限りのコードと PKCE verifier の交換。
- `POST /api/sapix/auth/revoke`: 現在の端末の採点トークンを失効。
- `GET /api/sapix/records`: 認証された所有者の記録を取得。
- `POST /api/sapix/records`: 記録単位の操作を適用し、同期結果を取得。

採点API用の認証は教材追加の合言葉、Studioセッション、GitHub Actions用の認証とは分離します。既存シークレットを再利用するため、この機能の導入にシークレットの追加・ローテーションは不要です。Worker と Pages の両方を公開してください。
