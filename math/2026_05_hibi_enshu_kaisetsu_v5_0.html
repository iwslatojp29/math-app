05月01　5つの整数の2数和から元の数を復元する

出典: 明治大付八王子・2回 / 掲載: 問題: 本誌18頁 / 解答: 本誌28頁

答え: (1) 12　(2) A+D と B+C

問題の要約: 小さい順に並ぶ5整数 A〜E について、10通りの2数和が 23, 29, 30, 31, 34, 35, 37, 41, 42 の9種類しかない。E-A と、同じ和になる2つの式を求める。

表向きの分野: 整数・和と差

実際に効いている見方: 2数和を大きさ順に並べ、端の和から差を作る見方

構造的な急所: 10通りあるはずの和が9種類しかないので、重なりは1組だけ。最小と最大の和を固定すると、E-A が一気に見える。

一言でいう勝ち筋: A+B, A+C, C+E, D+E のような端の和を対応させ、差を先に出してから残りを埋める。

1. 解く前の観察タイム

  1. 求めるのは値そのものではなく、まず E-A と重なる和の組だと確認する。
  2. 5個から2個を選ぶ和は本来10通りなのに、並んでいるのは9種類だけだと気づく。ここが最強条件。
  3. 最小の23は A+B、最大の42は D+E と決められる。端の和は必ず先に見る。
  4. 29は A+C、41は C+E と読めそうかを確かめる。A+E や B+D は中ほどに来る。
  5. 表向きは整数問題だが、本質は『順序つきの和の表をどう読むか』の整理問題である。

2. 初見での観察の順番

  1. 何を求める問題かを言い直す。今回は『12を出すには何を先に固定すればよいか』を見る。
  2. 一番強い条件『10通りの和が9種類しかないこと』を先に抜き出す。
  3. その条件を『和の一覧を『小さい順の2数和の並び』に翻訳する』に翻訳する。
  4. 図・表・帯図などの表現として『A行, B行, C行の2数和を三角形の表に置いて大小関係を見る』を選ぶ。
  5. 入口候補として『まず大小順の並びを見る方法と、値を直接復元する方法を候補にする』を並べ、第一候補から3分だけ試す。

3. 入口候補

候補A：和を並び順で読む

  • 何を見て立つ候補か: 23 と 42 が端の和だと読めるので、一覧全体を A+B < A+C < … の形に並べたくなる。
  • 最初に試す操作: A+B, A+C, A+D, A+E と B+C, B+D, B+E と C+D, C+E, D+E の大小関係を書く。
  • うまくいくサイン: 端の和が具体的に対応し、E-A のような差がすぐ作れる。
  • うまくいかないサイン: 大小関係が曖昧なまま数字だけ追い始めると途中で迷う。
  • この候補の位置づけ: 第一候補。重なりが1組しかないことと相性がよい。

候補B：整数そのものを復元する

  • 何を見て立つ候補か: A+B=23, D+E=42 などから各値を出したくなる。
  • 最初に試す操作: A, B, C, D, E を未知数として、まず差 E-A を作れないか探す。
  • うまくいくサイン: 一度 E-A が出ると A+D, B+E などが連鎖的に埋まる。
  • うまくいかないサイン: 最初から5個全部を方程式で追うと式が多くなりすぎる。
  • この候補の位置づけ: 候補Aが通った後の補助候補。単独で押し切るより、並び順と併用すると速い。

4. 小実験

  • 4個の整数 P<Q<R<S で2数和が5種類しかない場合を先に試す。『本来6通りなのに1組重なる』感覚がつかめる。
  • 最小和と最大和だけを抜き出して差を取る練習をする。端の和どうしは元の数の差を作りやすい。
  • A+E のような離れた和は中ほどに来ることを確認する。端の数字だけでなく位置の情報が使えると分かる。
  • 本番では、小実験で見えた『端から差を作る』手順をそのまま戻す。

5. 困ったときの6つの武器

武器 有効度 この問題で最初にやること 期待する観察
具体的な数で試す○4個版で『6通りが5種類になる』例を作る。重なり1組の見え方が分かる。
逆から考える◎最小和23と最大和42から差を作れるか試す。E-A を先に出せる。
図や表に整理する◎2数和の三角表を書く。どの和が端・中ほどかが見える。
条件を一つ外して考える○和が10種類すべて異なる場合と比べる。今回だけ重なり1組がある意味が見える。
似た問題を類推する○4整数の2数和問題を思い出す。端から読む型が再利用できる。
極端な場合を調べる◎最小和・最大和だけを先に固定する。A+B と D+E が確定する。

6. 見切りと切り替え

  • 進展のサインは、23, 29, 41, 42 をどの式に対応させるかが自然に決まること。
  • 行き詰まりのサインは、30, 31, 34, 35, 37 を眺めるだけで順序の根拠がなくなること。
  • その場合は数字追いを止め、A+B < A+C < … の三角表へ戻す。
  • 切り替え後の最初の一手は、『最小和と最大和を含む式だけ』を書き出すこと。

7. 解答解説の詳細分解

ステップ 何をしているか なぜ自然か 使っている条件 / 見えるようになること / つまずきやすい点
第1手 2数和10通りの大小関係を三角形の表に並べ、23 を A+B、29 を A+C、41 を C+E、42 を D+E と読む。 小さい順の整数なら、最小和と最大和は端の数を使う式に必ずなるから。
  • 使っている条件: A<B<C<D<E、和が9種類しかないこと
  • 見えるようになること: E-A=(C+E)-(A+C)=41-29 と作れる準備が整う。
  • つまずきやすい点: 41 を B+E と見てしまうと、その後の順序が崩れる。
第2手 E-A=41-29=12 を出す。 求めるものの一つが差なので、端の和の差に翻訳するのが最短だから。
  • 使っている条件: A+C=29、C+E=41
  • 見えるようになること: 元の数の幅が12と分かり、A+D や B+E を逆算できる。
  • つまずきやすい点: A+E と D+E を混同すると差の向きがぶれる。
第3手 A+D=D+E-(E-A)=42-12=30、B+E=A+B+(E-A)=23+12=35 を出し、37 は C+D だと決める。 差が出た後は、既知の和に 12 を足し引きして空欄を埋めると早いから。
  • 使っている条件: D+E=42、A+B=23、E-A=12
  • 見えるようになること: 残る D と E の差が (C+E)-(C+D)=41-37=4 と分かる。
  • つまずきやすい点: 37 を B+D と仮定すると残りが合わなくなる。
第4手 E-D=4 から A+E=34、B+D=31 を出し、30 になるのは A+D と B+C の組だと確定する。 残りの和を順に埋めると、まだ使っていない式がどれか分かるから。
  • 使っている条件: C+E=41、C+D=37、A+D=30、B+E=35
  • 見えるようになること: 重なった1組が確定し、答えがそろう。
  • つまずきやすい点: 最後に『まだ未使用の式』を確認しないと取り違えやすい。

8. 別解と多面的理解

別解として、A=11, B=12, C=18, D=19, E=23 まで全部復元してから確認してもよい。ただし教育的には、『値を全部出す前に差を先に抜く』本解の方が構造が見えやすい。

9. 失敗シミュレーション（誤答・失敗データ融合版）

失敗パターンA：最初から5個全部を未知数にして総当たりする

  • 誤った入口: A,B,C,D,E を一度に出そうとする。
  • なぜもっともらしく見えるか: 整数問題なので『まず値を出したい』気持ちが強いから。
  • なぜ誤りなのか: 和の順序情報を使っていないので式が多く、重なり1組の意味が死んでしまう。
  • 危険信号: 23や42がどの式か決まらないまま式だけ増える。
  • 切り替え先: 和の三角表を書いて端の和から読む。
  • この失敗から学ぶこと: この問題は値そのものより、和の位置関係が主役。

失敗パターンB：30や31など中ほどの和から手を付ける

  • 誤った入口: 真ん中の数字を先に当てはめる。
  • なぜもっともらしく見えるか: 中ほどの数字が多く、どれかに対応しそうに見えるから。
  • なぜ誤りなのか: 中ほどの和は候補が多く、根拠が弱い。
  • 危険信号: 対応が複数通りあり、すぐ行き止まる。
  • 切り替え先: 必ず23と42から固定する。
  • この失敗から学ぶこと: 端から見ると候補が一気に減る。

方針は合っているが詰まりやすい点

  • つまずきやすい局面: A+C=29 と C+E=41 から E-A を出した後、37の正体を決める場面。
  • どこで止まりやすいか: 31,34,35,37 が残って迷う。
  • 見落としやすいこと: まだ使っていない式がどれかを追っていない。
  • その場で確認すること: A+D, A+E, B+D, B+E, C+D のうち、すでに分かったものを消す。
  • 次の一手へ進む補助問い: 『E-A=12 を足し引きして決まる和はどれか。残る1つは何か。』

元の問題と同じ構造である理由

  • 見た目は4個の整数だが、本質は『本来6通りある2数和が1組重なる』こと。
  • 最小和と最大和から端の数の差を作る構造が同じ。

再利用する武器

  • 最小和= P+Q、最大和=R+S を固定する。
  • 次の和を P+R、Q+S などへ対応させる。

子どもへの問い

転移テストの解答解説

  • 入口: 14=P+Q, 25=R+S, 17=P+R と読む。
  • 考え方の骨組み: S-P=(R+S)-(P+R)=25-17。
  • 答え: 8
  • 元問題との共通点: 端の和の差で元の数の差を出している。

05月02　同じ所持金と残金の差から単価を割り出す

出典: 大谷（大阪）・C / 掲載: 問題: 本誌18-19頁 / 解答: 本誌28頁

答え: (1) 120円　(2) 70円　(3) 800円

問題の要約: A・B・C の3人は同じ金額を持って店に行き、鉛筆と消しゴムを違う本数ずつ買った。残金の差から、鉛筆1本と消しゴム1個の合計、消しゴム1個の値段、Aさんの最初の所持金を求める。

表向きの分野: 文章題・買い物

実際に効いている見方: 同額所持なので『買った額の差＝残金の差』とみる見方

構造的な急所: A と B を比べると、買い方の差がちょうど『鉛筆1本+消しゴム1個』になっている。まず束で見ると式が短くなる。

一言でいう勝ち筋: 残金の差から えんぴつ+消しゴム を出し、その束を何個ぶん戻すかで消しゴムを単独にする。

1. 解く前の観察タイム

  1. 3人の最初の所持金が同じ、という条件が最重要だと見る。
  2. A と B の買い方を比べると、B は A より『鉛筆1本と消しゴム1個』多く買っている。
  3. 買った額そのものは分からなくても、残金の差 490-370=120 はその束の値段だと読める。
  4. A と C は本数がそろっていないので、いきなり比べる前に束を何回ぶん戻せば同じ形になるか考える。
  5. 表向きは買い物の文章題だが、本質は『差を束に翻訳してから単品に戻す』問題である。

2. 初見での観察の順番

  1. 何を求める問題かを言い直す。今回は『120円を出すには何を先に固定すればよいか』を見る。
  2. 一番強い条件『3人の最初の所持金が同じこと』を先に抜き出す。
  3. その条件を『残金の差を、買い方の差に翻訳する』に翻訳する。
  4. 図・表・帯図などの表現として『『鉛筆1本+消しゴム1個』を1束として線分やメモでそろえる』を選ぶ。
  5. 入口候補として『残金差で束を作る方法と、連立にする方法を並べる』を並べ、第一候補から3分だけ試す。

3. 入口候補

候補A：残金の差で束を見る

  • 何を見て立つ候補か: 同額所持なら、残金の差は買った物の差そのものになる。
  • 最初に試す操作: A と B の残金差 120円 を『鉛筆1本+消しゴム1個』と読む。
  • うまくいくサイン: 1束の値段が決まり、A と C も束を戻してそろえられる。
  • うまくいかないサイン: 残金をそのまま足したり引いたりしても単価には近づかない。
  • この候補の位置づけ: 第一候補。条件を最も素直に使える。

候補B：鉛筆を p 円、消しゴムを e 円と置く

  • 何を見て立つ候補か: 式で整理したいときの候補。
  • 最初に試す操作: 2p+3e, 3p+4e, 1p+5e の差をとって短い式を作る。
  • うまくいくサイン: p+e=120 がすぐ出れば本解と同じ形に合流できる。
  • うまくいかないサイン: 最初から3本分を書き並べると式は立つが見通しが悪い。
  • この候補の位置づけ: 候補Aの確認用。

4. 小実験

  • 『同額所持で、片方が1個ずつ多く買った』だけの2人版を先に考える。残金差がそのまま1束になる感覚を作る。
  • 鉛筆と消しゴムを別に見る前に、まず 1束=鉛筆1本+消しゴム1個 と置く。
  • A の買い方 2本3個から束を2回戻すと 0本1個、C の買い方 1本5個から束を1回戻すと 0本4個 になり、差が消しゴム3個だけになる。
  • 本番では、この『束を戻して単品差にする』手順をそのまま使う。

5. 困ったときの6つの武器

  • 行き詰まりのサインは、p と e の式が3本並んで長く感じること。

7. 解答解説の詳細分解

ステップ 何をしているか なぜ自然か 使っている条件 / 見えるようになること / つまずきやすい点
第1手 A と B を比べ、残金差 490-370=120 を『鉛筆1本+消しゴム1個』の値段と読む。 同じ所持金で、B が A より 1本1個多く買っているから。
  • 使っている条件: 同額所持、A:2本3個、B:3本4個
  • 見えるようになること: 鉛筆+消しゴム の束の値段が120円と分かる。
  • つまずきやすい点: 『多く買った側の残金が少ない』向きを逆にしないこと。
第2手 A の買い方から束を2回戻して『消しゴム1個』に、C の買い方から束を1回戻して『消しゴム4個』にそろえる。 単品価格を知りたいので、束を戻して同じ種類だけにするのが自然だから。

  4. 候補Aが3分以内に進まなければ、表や図に戻して候補Bへ切り替える。
  5. 答えが出たら、同じ型なら次に何を先に見るかを1行で残す。

05月29　駅ごとの乗り降りを区間人数に直す

出典: 渋谷教育学園渋谷 / 掲載: 問題: 本誌27頁 / 解答: 本誌37頁

答え: (1) 62000円　(2) 71820円　(3) 13人

問題の要約: A-B-C-D の4駅を走る電車で、各区間の運賃表がある。朝・昼・夕方の3場面について、駅ごとの乗り降り情報や総運賃から、乗客全員の運賃合計や A駅から乗ってC駅で降りた人数を求める。

表向きの分野: 文章題・乗客の流れ

実際に効いている見方: 駅ごとの乗り降りを、A→B, A→C, A→D, B→C, B→D, C→D の6区間人数に翻訳する見方

構造的な急所: 『今何人乗っているか』だけではなく、『どの区間に属する人数か』へ直すと運賃合計がかけ算で出る。夕方は total から AB と CD を引いて面積図にするのが急所。

一言でいう勝ち筋: 6種類の区間人数を置き、駅条件で埋め、最後に運賃を掛ける。

1. 解く前の観察タイム

  1. 運賃は区間ごとに決まるので、人数も区間ごとに持たないと合計を出しにくい。
  2. 未知数は A→B, A→C, A→D, B→C, B→D, C→D の6つと決めると整理しやすい。
  3. (1) は区間人数がほぼ直接決まる基本形。
  4. (2) は C駅の条件から先に 乗る人数22・降りる人数55 が出るのが強い。
  5. (3) は総額64390円から AB区間と CD区間の既知部分を引き、残りを面積図で読むのが急所。

2. 初見での観察の順番

  1. 何を求める問題かを言い直す。今回は『62000円を出すには何を先に固定すればよいか』を見る。
  2. 一番強い条件『運賃が区間ごとに違うこと』を先に抜き出す。
  3. その条件を『駅での乗り降りを6種類の区間人数に翻訳する』に翻訳する。
  4. 図・表・帯図などの表現として『6本の区間帯図、または面積図』を選ぶ。
  5. 入口候補として『まず区間人数を置く、夕方は面積図』を並べ、第一候補から3分だけ試す。

3. 入口候補

候補A：6区間人数を置く

  • 何を見て立つ候補か: 運賃表がそのまま6区間を示しているから。
  • 最初に試す操作: A→B, A→C, A→D, B→C, B→D, C→D を文字で置く。
  • うまくいくサイン: 条件を駅ごとに整理できる。
  • うまくいかないサイン: 乗車中人数だけを追うと運賃合計に結びつきにくい。
  • この候補の位置づけ: 第一候補。

候補B：総額から既知区間を引いて面積図にする

  • 何を見て立つ候補か: (3) は数を直接置くより、残りの金額を図で読む方が速い。
  • 最初に試す操作: 64390円から AB と CD の既知部分を引く。
  • うまくいくサイン: A→C の人数がつるかめ算で出る。
  • うまくいかないサイン: いきなり6変数連立にすると重い。
  • この候補の位置づけ: (3) の第一候補。

4. 小実験

  • A-B-C の3駅版で、A→B, A→C, B→C の3区間人数に分ける練習をする。
  • (1) の朝の条件で、終点Dまで行く人数を先に描く。
  • (2) では C駅での『降りた人が乗った人の2.5倍で差33』から人数を先に出す。
  • (3) では残りの金額を長方形の面積図にする。

5. 困ったときの6つの武器

武器 有効度 この問題で最初にやること 期待する観察
具体的な数で試す○1人や3駅版の簡単版で表の意味を確認する。表や区間の読み方が分かる。
逆から考える△総額から人数や区間人数を戻す。使える場面は限られるが、基準になる。
図や表に整理する◎区間表・列ごとの式・面積図を作る。情報がぶつからずに並ぶ。
条件を一つ外して考える○まず1駅/1列だけを見る。最強条件がどこか分かる。
似た問題を類推する○鶴亀算や乗客流動の基本問題に寄せる。人数復元の筋が見える。
極端な場合を調べる◎全員同じ払い方・全員終点まで、など基準を置く。差の列が一気に決まる。

6. 見切りと切り替え

  • 進展のサインは、どの場面でも6区間人数に直せること。
  • 行き詰まりのサインは、駅ごとの乗車中人数だけで総額を出そうとすること。
  • その場合は運賃表の6区間に戻る。
  • 切り替え後は、場面ごとに一番強い条件から人数を埋める。

7. 解答解説の詳細分解

ステップ 何をしているか なぜ自然か 使っている条件 / 見えるようになること / つまずきやすい点
第1手 (1) 朝は Aで100人、Bで15人降り、Cで20人乗り、Dで全員降り。したがって A→D が85人、A→B が15人、C→D が20人。運賃合計は 600×85+200×15+400×20=62000円。 区間人数がほぼ直接読める基本形だから。
  • 使っている条件: 朝の乗り降り条件
  • 見えるようになること: 1問目がそのまま計算できる。
  • つまずきやすい点: A→C や B→D を0人と見落とさない。
第2手 (2) 昼は C駅の条件から、乗った人数22人・降りた人数55人。さらにB駅では『乗った人数=降りた人数の4倍』より Bで降りた9人、乗った36人。これを6区間人数に戻すと、各区間人数が埋まり、総額は71820円。 C駅の2.5倍と差33が最も強い条件だから。
  • 使っている条件: 昼のC駅条件、B駅条件、Dで94人降車
  • 見えるようになること: 6区間人数が確定し、2問目の総額が出る。
  • つまずきやすい点: 乗った人数と降りた人数のどちらが多いかの向きを間違えない。
第3手 (3) 夕方は AB区間の200円×15人 と CD区間の400円×10人 を総額64390円から引く。残り57390円を、300円・350円・580円・600円の帯図にすると、A→C の人数だけがつるかめ算の『高い方』になり 13人。 既知区間を先に引くと、残りが2種類の面積図に整理できるから。
  • 使っている条件: 総額64390円、Bで15人降り20人乗る、Cで20人降り10人乗る
  • 見えるようになること: 3問目の A→C が13人と出る。
  • つまずきやすい点: AB と CD の既知人数を引き忘れると図が作れない。

8. 別解と多面的理解

流れの問題では、乗車中人数だけでなく『どこからどこまで』の区間人数に直す力が重要。夕方の面積図は転移価値が高い。

9. 失敗シミュレーション（誤答・失敗データ融合版）

失敗パターンA：表を読まずに式だけ立てる

  • 誤った入口: 列の意味や区間の意味を曖昧なまま計算する。
  • なぜもっともらしく見えるか: 数字が多いので早く式にしたくなるから。
  • なぜ誤りなのか: 支払いとおつり、乗車中人数と区間人数が混ざる。
  • 危険信号: 符号や区間の対応でミスが出る。
  • 切り替え先: まず表の各列・各区間の意味を日本語で言い直す。
  • この失敗から学ぶこと: 表題の意味づけが先、式は後。

失敗パターンB：全部の列/駅を同時に追う

  • 誤った入口: 100円・50円・10円や各駅条件を一気に処理する。
  • なぜもっともらしく見えるか: 全部使いたくなるから。
  • なぜ誤りなのか: 最強条件が埋もれてしまう。
  • 危険信号: 式が多いのに未知数が減っていない。
  • 切り替え先: 人数や強い駅条件など、最初に決まる1本へ絞る。
  • この失敗から学ぶこと: 順番を選ぶだけで難度が下がる。

方針は合っているが詰まりやすい点

  • つまずきやすい局面: 一部が決まった後、残り1列・1区間を詰める場面。
  • どこで止まりやすいか: 符号や『乗る/降りる』の向きで迷う。
  • 見落としやすいこと: 基準から見て増えるのか減るのか。
  • その場で確認すること: 手元に残る枚数か、おつりとして減る枚数か。乗車中か、ある区間に属する人数か。
  • 次の一手へ進む補助問い: 『今数えているのは何の人数・何の枚数か。』

13. 転移テスト

転移テスト問題

A-B-C の3駅を走るバスで、A→B 200円、A→C 350円、B→C 180円。Aで40人乗り、Bで10人降り5人乗り、Cで全員降りた。運賃合計を求めなさい。

元の問題と同じ構造である理由

  • 駅の情報を区間人数に直す。

再利用する武器

  • A→B, A→C, B→C の3区間に分ける。

子どもへの問い

Bで降りた10人はどの区間の人？

転移テストの解答解説

  • 入口: A→B が10人、B→C が5人、A→C が30人。

  • 答え: 200×10+350×30+180×5
  • 元問題との共通点: 区間人数を置いてから総額を出している。
