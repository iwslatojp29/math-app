中学受験算数｜電車の運賃問題

乗り降りを「乗車区間別の人数」に変換する問題

この問題の急所は、駅ごとの人数変化を追うだけでなく、運賃表に合わせて A→B, A→C, A→D, B→C, B→D, C→D の人数表を作ることです。

（1）
62000円
（2）
71820円
（3）
13人

目次

0. 初見での見方 1. 基本の型 2. （1）の解説 3. （2）の解説 4. （3）の解説 5. 難問力がつく見方 6. 失敗しやすい考え方 7. （3）の差分解法 8. 一般化と再現手順

0. 初見での見方

まず運賃表を見ると、必要なのは次の6種類の人数だと分かります。

乗車区間運賃
A→B200円
A→C350円
A→D600円
B→C300円
B→D580円
C→D400円
初見の最重要視点
「いま電車に何人乗っているか」だけでは、運賃合計は出せません。同じD駅で降りる人でも、Aから乗った人、Bから乗った人、Cから乗った人では運賃が違うからです。
① 駅ごとの乗降
何人乗ったか、何人降りたかを読む。
② 乗車区間別の人数
A→Bなど、運賃表と同じ単位に直す。
③ 運賃をかける
人数 × 運賃 を合計する。
難問力メモ
この問題は「乗客数を追う問題」に見えますが、本質は「運賃表の形に合わせて人数表を作り直す問題」です。難問では、表面の条件と本当に必要な情報がズレていることがよくあります。

1. 基本の型

最初に、次の表を頭の中に作ります。

乗車区間人数
A→B?
A→C?
A→D?
B→C?
B→D?
C→D?

駅ごとの条件は、次のように読み替えます。

  • B駅で降りる人は、必ず A→B。
  • B駅で乗る人は、B→C または B→D。
  • C駅で降りる人は、A→C または B→C。
  • C駅で乗る人は、必ず C→D。
  • D駅で降りる人は、A→D, B→D, C→D。
合言葉
運賃表が「出発駅→到着駅」ごとにあるなら、人数も「出発駅→到着駅」ごとに分ける。

2. （1）の解説

条件A駅で100人乗る。B駅で15人降り、誰も乗らない。C駅では誰も降りず、20人乗る。D駅で全員降りる。

乗車区間ごとに決める

A駅で乗った100人のうち、B駅で15人降りました。

A→B = 15

残りは 100 − 15 = 85 人です。C駅では誰も降りないので、この85人はD駅まで行きます。

A→D = 85

C駅で乗った20人はD駅まで行きます。

C→D = 20
乗車区間人数運賃小計
A→B15人200円3000円
A→D85人600円51000円
C→D20人400円8000円
15×200 + 85×600 + 20×400 = 3000 + 51000 + 8000 = 62000
答え
（1）は 62000円 です。

3. （2）の解説

条件A駅で100人乗る。B駅では、乗った人数が降りた人数の4倍。C駅では、降りた人数が乗った人数の2.5倍で、降りた人は乗った人より33人多い。C駅で降りた人のうち、A駅から乗った人はB駅から乗った人より21人多い。D駅では94人が全員降りる。

3-1. C駅の乗降人数を先に決める

C駅で乗った人数を c 人とします。降りた人数はその2.5倍で、しかも乗った人数より33人多いので、

2.5c = c + 33
1.5c = 33
c = 22

したがって、C駅で乗った人数は22人、降りた人数は55人です。

C駅で乗る = 22人，C駅で降りる = 55人

3-2. B駅の乗降人数を決める

B駅で降りた人数を b 人とします。B駅で乗った人数はその4倍なので 4b 人です。

B駅を出た直後の人数は、

100 − b + 4b = 100 + 3b

C駅では55人降り、22人乗るので、C駅を出た直後の人数は、

100 + 3b − 55 + 22 = 67 + 3b

D駅で94人が全員降りたので、C駅を出た直後に乗っていた人数は94人です。

67 + 3b = 94
3b = 27
b = 9

よって、B駅で降りる人数は9人、乗る人数は36人です。

駅乗る人数降りる人数
A駅100人0人
B駅36人9人
C駅22人55人
D駅0人94人

3-3. 乗車区間ごとに分ける

B駅で降りた9人は、A駅から乗ってB駅で降りた人です。

A→B = 9

C駅で降りた55人は、A駅から来た人とB駅から来た人の合計です。

A→C + B→C = 55

さらに、A駅から乗った人はB駅から乗った人より21人多いので、

A→C = B→C + 21

B→Cを x 人とすると、A→Cは x + 21 人です。

x + (x + 21) = 55
2x = 34
x = 17

したがって、

B→C = 17，A→C = 38

3-4. 残りを決める

A駅から乗った100人は、A→B、A→C、A→Dに分かれます。

A→D = 100 − 9 − 38 = 53

B駅から乗った36人は、B→C、B→Dに分かれます。

B→D = 36 − 17 = 19

C駅から乗った22人は全員D駅までです。

C→D = 22
乗車区間人数運賃小計
A→B9人200円1800円
A→C38人350円13300円
A→D53人600円31800円
B→C17人300円5100円
B→D19人580円11020円
C→D22人400円8800円
1800 + 13300 + 31800 + 5100 + 11020 + 8800 = 71820
答え
（2）は 71820円 です。

4. （3）の解説

条件A駅で100人乗る。B駅では15人降り、20人乗る。C駅では20人降り、10人乗る。D駅で全員降りる。運賃合計は64390円。A駅から乗ってC駅で降りた人数を求める。

4-1. 求める人数を置く

A駅から乗ってC駅で降りた人数を x 人とします。

A→C = x

4-2. 乗車区間ごとに表す

A駅で100人乗り、B駅で15人降ります。B駅で降りた人は全員A→Bです。

A→B = 15

A駅から乗った100人のうち、A→Bが15人、A→Cが x 人なので、残りはA→Dです。

A→D = 100 − 15 − x = 85 − x

C駅で降りた人は20人です。そのうちA→Cが x 人なので、B→Cは、

B→C = 20 − x

B駅で乗った20人のうち、B→Cが 20 − x 人なので、残りはB→Dです。

B→D = 20 − (20 − x) = x

C駅で乗った10人はD駅まで行きます。

C→D = 10
乗車区間人数
A→B15人
A→Cx人
A→D85 − x 人
B→C20 − x 人
B→Dx人
C→D10人
ここが一番大事
A→C = x と置くと、C駅で降りる20人の残りが B→C = 20 − x になり、その結果 B→D = x になります。1つの文字が、別の区間にも連動して現れるところがこの問題の構造です。

4-3. 運賃合計の式を作る

15×200 + x×350 + (85−x)×600 + (20−x)×300 + x×580 + 10×400 = 64390

定数部分と x の部分を分けます。

15×200 = 3000
(85−x)×600 = 51000 − 600x
(20−x)×300 = 6000 − 300x
3000 + 350x + 51000 − 600x + 6000 − 300x + 580x + 4000 = 64390
64000 + 30x = 64390
30x = 390
x = 13
答え
A駅から乗ってC駅で降りた人は 13人 です。

5. 難問力がつく見方

この問題で伸ばしたい力は、単なる計算力ではなく、情報を必要な形に変換する力です。

5-1. 表面の情報と本当に必要な情報を分ける

表面に見えている情報本当に必要な情報
B駅で何人降りたA→Bが何人か
C駅で何人降りたA→CとB→Cが何人か
D駅で全員降りたA→D、B→D、C→Dが何人か

このズレに気づくことが、構造認識です。

5-2. 入口候補は2つある

入口A
電車内の人数変化を追う。
（2）では特に有効。
入口B
乗車区間表を作る。
運賃計算に必ず必要。
実戦の流れ
駅ごとの人数 → 乗車区間表 → 運賃合計。

5-3. 小実験として見るなら

3駅だけの小さい電車 A—B—C で考えると、必要な人数は A→B, A→C, B→C の3つだけです。

  • Bで降りた人数は A→B。
  • Bで乗った人数は B→C。
  • Cで降りた人数は A→C + B→C。

これを4駅に増やすと、今回の6種類になります。小さいモデルで考えると、なぜ乗車区間表が必要なのかが見えやすくなります。

Wordファイルの論点との接続
難問力は「ひらめき」ではなく、内容知識・構造認識・メタ認知・設計された練習の組み合わせとして育てる、という立場で整理できます。この問題では、内容知識は「表を作る」「文字を置く」、構造認識は「運賃表に合わせて人数表を作る」、メタ認知は「人数変化だけでは足りないと気づいて切り替える」ことに当たります。

6. 失敗しやすい考え方

失敗1：線路の区間料金だと思ってしまう
A→Dの運賃は600円です。しかし、A→B、B→C、C→Dを足すと 200 + 300 + 400 = 900円 になります。つまり、この表は「線路一区間ごとの料金」ではなく、「乗った駅から降りた駅までの料金」です。
失敗2：D駅で降りた人数だけで決めようとする
D駅で降りる人には、A→D、B→D、C→Dが混ざっています。同じD駅で降りても運賃が違うので、D駅で何人降りたかだけでは不十分です。
失敗3：（3）でB→Dもxになることを見落とす
A→C = x とすると、C駅で降りる20人の残りが B→C = 20 − x になります。B駅で乗った20人の残りなので、B→D = x です。

7. （3）の別解：差分で見る

（3）は、式を作らずに「基準からの差」で見ることもできます。

7-1. まず x = 0 の場合を考える

乗車区間人数
A→B15人
A→D85人
B→C20人
C→D10人
15×200 + 85×600 + 20×300 + 10×400 = 64000

実際の合計は64390円なので、差は、

64390 − 64000 = 390

7-2. xが1増えるとどう変わるか

変化運賃の変化
A→Dが1人減り、A→Cが1人増える350 − 600 = −250円
B→Cが1人減り、B→Dが1人増える580 − 300 = +280円
合計+30円

つまり、x が1増えるごとに、合計運賃は30円増えます。

390 ÷ 30 = 13
差分解法の答え
A駅から乗ってC駅で降りた人は 13人 です。

8. 一般化と再現手順

8-1. この問題の一般化

再利用できる型
運賃表が「出発駅→到着駅」ごとにあるなら、人数も「出発駅→到着駅」ごとに分ける。駅ごとの乗降人数だけで運賃を出そうとしない。

8-2. 子ども向けの再現手順

  1. 運賃表を見て、必要なのは「A→Bなどの乗車区間別人数」だと考える。
  2. B駅で降りた人はA→B、C駅で乗った人はC→Dのように、確定するものから入れる。
  3. 中間駅で降りた人は、どこから来た人が混ざっているかを分ける。
  4. 最後に、人数表に運賃をかけて合計する。
  5. 合計運賃が与えられている問題では、残った人数を x と置いて式を作る。

8-3. 仕上げの合言葉

運賃表に合わせて、人数表を作る。
この一文を覚えておくと、同じ構造の問題に出会ったときに入口が見つけやすくなります。
指導者向け補足

この問題は、計算処理よりも「表現の変換」を評価する問題です。指導時は、いきなり計算させるより、まず「何の人数が分かれば運賃を出せるか」を言語化させると効果的です。特に（3）は、A→C = x と置いたときに B→D = x も出てくる連動構造を確認させると、難問での文字設定の力につながります。
