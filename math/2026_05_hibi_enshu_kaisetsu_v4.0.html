05月01　問題1

出典: 明大付八王子・2回　/　掲載: 問題 p.18 / 解説 p.28

答え: （1）12　（2）A＋D と B＋C

問題の要約: 5つの整数 A, B, C, D, E（小さい順）から2つを選んだ和が 23, 29, 30, 31, 34, 35, 37, 41, 42 の9種類になる。E−A と、和が等しくなる2つの式を求める。

表向きの分野: 整数の和

実際に効いている見方: 並び順から和の大小関係を固定し、同じ相手との和の差で E−A を抜く問題

構造的な急所: A＜B＜C＜D＜E と並んでいること、2数の和が10通りあるのに9種類しかないこと

一言でいう勝ち筋: 10個の和を順序つきで並べ、端の和とその近くの和を引いて差を作る。

1. 解く前の観察タイム

  1. まず『A＜B＜C＜D＜E』が最大の武器です。順番があるので、和 A＋B, A＋C, …, D＋E に大小関係がつきます。
  2. 5個から2個の取り方は 10 通りなのに、和は 9 種類しかありません。どこかで1組だけ重なります。
  3. 最小の和は A＋B＝23、最大の和は D＋E＝42 とすぐ置けます。端が分かると差を作りやすくなります。
  4. 41 が C＋E と読めるのが重要です。最大の 42 の一つ手前なので、相手を E にそろえて E−A を引けます。
  5. 表向きは整数問題ですが、本質は『順序つきに並べて差を取る』和差算です。

2. 初見での観察の順番

  1. 和10個を順番どおりに並べる: 順序を固定しないと、どの数がどの和かが見えません。
  2. 最小・最大・その近くの和を確定する: 23, 41, 42 のような端の情報から差が作れます。
  3. 重なり候補を最後に確定する: 30 が重なりそうだと見えてから、残りを埋めるのが自然です。

3. 入口候補

候補A：和を順に並べて埋める

  • 何を見て立つ候補か: 整数が小さい順に並ぶという条件が強いので、和にもほぼ一列の並びができます。
  • 最初に試す操作: A＋B＜A＋C＜A＋D＜A＋E と、B＋C＜B＋D＜B＋E、C＋D＜C＋E＜D＋E を書く。
  • うまくいくサイン: 端の 23, 41, 42 を自然に置ける。
  • うまくいかないサイン: 並びを書かずに数当てを始めると、条件の強さを捨ててしまう。
  • この候補の位置づけ: この問題の最も強い条件を最初から使える第一候補です。

候補B：実際の値 A, B, C, D, E を決めにいく

  • 何を見て立つ候補か: 和の一覧から元の整数そのものを復元したくなります。
  • 最初に試す操作: A＋B=23, D＋E=42 から和差を作って候補を絞る。
  • うまくいくサイン: 最後に A=11, B=12, C=18, D=19, E=23 まで確認できます。
  • うまくいかないサイン: 最初から5個すべてを決めようとすると方程式が散らかる。
  • この候補の位置づけ: 検算としては有効ですが、入口としては候補Aより一段重いです。

4. 小実験

  • 最初の小実験は『10個の和を実際に並べる』ことです。
  • 観察したいのは、どの位置の和どうしを引けば E−A や E−D のような差が出るかです。
  • 本番では 41−29=(C＋E)−(A＋C)=E−A のように、同じ相手 C や E をそろえて差に戻します。

5. 困ったときの6つの武器

武器有効度この問題で最初にやること期待する観察
具体的な数で試す○23, 29, 41, 42 を仮に A＋B, A＋C, C＋E, D＋E と置いてみる。どの差が E−A になるかが見える。
逆から考える△最後の『重なる和』から入る手もある。ただし順序を先に作った方が安定する。
図や表に整理する◎10個の和を大小順の表にする。問題の骨組みが一気に見える。
条件を一つ外す○『9種類』を外すとただの並び問題。重なりがあることが核心だと分かる。
似た問題を類推する○等差数列や和差算の『同じ相手で引く』型を思い出す。差を抜く発想につながる。
極端な場合を調べる◎最小 23 と最大 42 から始める。端から埋めると迷いにくい。

6. 見切りと切り替え

  • 続行してよいサインは、41−29 のように『同じ相手をそろえた差』が作れたときです。
  • 行き詰まりのサインは、A, B, C, D, E の実数値を最初から全部決めようとして式が増えることです。
  • その場合はいったん戻って、和の並び表だけを丁寧に書き直します。

7. 解答解説の詳細分解

ステップ何をしているかなぜ自然か
第1手10個の和を大小順に並べる。A＋B＜A＋C＜A＋D＜A＋E、B＋C＜B＋D＜B＋E、C＋D＜C＋E＜D＋E と書けるのは A＜B＜C＜D＜E があるからです。
第2手A＋B=23, A＋C=29, C＋E=41, D＋E=42 を置く。最小と最大、その手前の 41 は並びの位置から自然に読めます。
第3手E−A=(C＋E)−(A＋C)=41−29=12 を出す。同じ C を相手にした和を引くと、和の問題が差の問題に変わります。
第4手A＋D=42−12=30, B＋E=23＋12=35 を出す。E−A が出たので、和を横にずらす操作ができます。
第5手37 は C＋D と確定し、E−D=(C＋E)−(C＋D)=41−37=4。残りの大きい和を埋めることで、次の差 E−D まで取れます。
第6手A＋E=30＋4=34, B＋D=35−4=31。同じ差を利用して残りを埋めると、30 は A＋D と B＋C の重なりだと分かります。

8. 別解と多面的理解

別視点として、実際に A=11, B=12, C=18, D=19, E=23 まで復元してしまう方法もあります。ただし教育的には、値当てより『同じ相手で引く』方が再利用しやすいです。

9. 誤答・失敗データ

  • 23 と 42 だけ見て A, E を決めようとする誤り。中の整数が残るので情報が足りません。
  • 和10通りを並べずに、30 がどの和かを当てにいく誤り。順序条件を使えていません。
  • 41 を B＋E と読む誤り。大きい和の位置関係を確認しないのが原因です。

10. 必要要素マップ

要素この問題での役割重要度見落とすとどうなるか
大小関係の整理和を順に並べる土台高どの和がどの位置か分からなくなる
和差算同じ相手で引いて差を出す高E−A が抜けない
重複の認識10通りが9種類という条件を使う中（2）の重なる式に届かない

11. 条件 → 手法メタ知識ネットワーク

  • A＜B＜C＜… がある → 和を大小順に表にする
  • 同じ相手との和が2つある → 引いて差に戻す
  • 取り方の数より種類が1少ない → 重なりが1組ある

12. 解けた後の一般化

  • 順番つきの数列が出たら、まず和・差・積の並び順を作る。
  • 和の問題で差を出したいときは『同じ相手』を探す。
  • 端の情報（最小・最大・その近く）は、難問の入口になることが多い。

13. 子ども向け再現手順

  1. 5個から2個の和を、大小が分かる順に並べる。
  2. 最小と最大、その近くの和を置いて E−A を出す。
  3. 出した差で残りの和を埋め、最後に重なる式を見つける。

14. 指導者向け補足

この問題の指導目標は『並び順を武器にする』ことです。値当ての問題に見せず、和の表を作るだけで景色が変わる経験をさせると、以後の和差・整数・相似の問題でも観察の質が上がります。

05月02　問題2

出典: 大谷（大阪）・C　/　掲載: 問題 pp.18-19 / 解説 p.28

答え: （1）120円　（2）70円　（3）800円

問題の要約: 同じ金額を持っていた A・B・C が、えんぴつと消しゴムを別々の個数だけ買った。残金 490円・370円・400円を使って、えんぴつ1本＋消しゴム1個、消しゴム1個、Aの最初の所持金を求める。

表向きの分野: 買い物の文章題

実際に効いている見方: 同じ所持金という条件の下で、残金の差を『買った物の差』に読み替える和差算

構造的な急所: 3人の最初の所持金が同じこと、A・B・C の買い方が少しずつずれていること

一言でいう勝ち筋: 残金差 → 買った物の差額、という向きに翻訳してから 1 本＋1 個、さらに消しゴムだけへ落とす。

1. 解く前の観察タイム

  1. 『同じ金額を持っていた』ので、比べるべきは支払った金額ではなく残金差です。
  2. A と B を比べると、B は A よりえんぴつ1本・消しゴム1個多く買っています。
  3. したがって 490−370=120 は『えんぴつ1本＋消しゴム1個』の値段です。
  4. 次は消しゴムだけにしたいので、買い方の差をさらにそろえます。
  5. 表向きは連立方程式ですが、本質は差の翻訳です。

2. 初見での観察の順番

  1. A と B の比較: 差が最もきれいで、1本＋1個がすぐ出ます。
  2. A と C の買い方をそろえる: えんぴつを消して消しゴムだけの差に落とします。
  3. 最初の所持金に戻る: 単価が出たら A の支払額を足して終わりです。

3. 入口候補

候補A：残金差から入る

  • 何を見て立つ候補か: 最初の所持金が同じなので、差を見れば買った物の差に一致します。
  • 最初に試す操作: A と B を引いて 120 円 = えんぴつ1本＋消しゴム1個 を出す。
  • うまくいくサイン: 式が少なく、単価の意味がはっきりする。
  • うまくいかないサイン: 支払額を直接文字で置くよりも、関係が見えやすい。
  • この候補の位置づけ: 問題文の強い条件をそのまま使う最短ルートです。

候補B：文字を2つ置く

  • 何を見て立つ候補か: えんぴつを p 円、消しゴムを g 円と置けば解けます。
  • 最初に試す操作: 2p+3g, 3p+4g, p+5g の差を取る。
  • うまくいくサイン: 確実ではある。
  • うまくいかないサイン: 小学生向けには『何の差か』が見えにくくなりやすい。
  • この候補の位置づけ: 検算用にはよいが、初見の入口は候補Aの方が自然です。

4. 小実験

  • 最初の小実験は A と B だけを比べることです。
  • 『同じ所持金なら、残金差＝買った物の差額』という翻訳が正しいかを確認します。
  • この翻訳が通ったら、A と C でも同じことをして消しゴムだけの差に進みます。

5. 困ったときの6つの武器

武器有効度この問題で最初にやること期待する観察
具体的な数で試す◎490−370 をまず計算する。1本＋1個が 120 円だと見える。
逆から考える○残金から初期所持金へ戻す。最後の一手が明確になる。
図や表に整理する○3人の買った個数差を表にする。何を引けばよいか見える。
条件を一つ外す△『同じ所持金』を外すと差が使えない。この条件の重さが分かる。
似た問題を類推する◎買い方を入れ替える和差算を思い出す。差額処理が自然になる。
極端な場合を調べる△今回は端より比較が有効。A-B が一番単純。

6. 見切りと切り替え

  • 1本＋1個が出た時点で前進です。そこから『えんぴつを消す』発想に移れます。
  • 文字式を増やしてしまったら、A-B の差へ戻すと立て直せます。

7. 解答解説の詳細分解

ステップ何をしているかなぜ自然か
第1手A と B の残金差を取る。同じ所持金なので、490−370=120 円は B が A より多く買った『えんぴつ1本＋消しゴム1個』の代金です。
第2手A と C を比べる準備をする。A が『えんぴつと消しゴムを2組少なく買ったあと消しゴム1個だけ買う』形、C が『1組少なく買ったあと消しゴム4個買う』形に直すと、残金がそれぞれ 730 円、520 円になります。
第3手730−520=210 円を消しゴム3個分と読む。よって消しゴム1個は 70 円です。
第4手120−70=50 でえんぴつ1本を出し、A の支払額を戻す。A の支払額は 2×50+3×70=310 円なので、初めの所持金は 490+310=800 円です。

8. 別解と多面的理解

文字式なら A-B から p+g=120、A-C から p−2g=90 としても解けます。ただし、この問題では『差が何を表すか』を日本語で言える方が価値があります。

9. 誤答・失敗データ

  • 490 円や 370 円をそのまま支払額だと思ってしまう誤り。
  • A と C の差をいきなり取って、えんぴつと消しゴムが混ざったまま迷う誤り。
  • 最後に初期所持金へ戻す一手を忘れる誤り。

11. 条件 → 手法メタ知識ネットワーク

  • 最初の所持金が同じ → 残金差は買った物の差額
  • 1組分の値段が出た → 組をそろえて片方だけの値段にする
  • 単価が出た → 残金に支払額を足して初期値へ戻る

12. 解けた後の一般化

  • 『同じ金額を持っていた』は、差で攻めるサインです。
  • 差が混ざっているときは、同じセットを増減して片方だけにする。
  • 買い物問題でも、まず式ではなく比較の日本語を作ると失敗しにくいです。

13. 子ども向け再現手順

  1. A と B を比べて、えんぴつ1本＋消しゴム1個を 120 円と出す。
  2. A と C を『組』でそろえて、消しゴム1個を 70 円と出す。
  3. A の買い物代を計算して、残金 490 円に足す。

14. 指導者向け補足

この問題は連立方程式の先取りではなく、『差が何を表すかを読む』練習として扱うのが効果的です。残金差を見た瞬間に比較へ行けるようになると、和と差の文章題全体が安定します。

05月07　問題7

出典: 星野学園・理数選抜2回　/　掲載: 問題 p.19 / 解説 pp.28-29

答え: （1）1230円　（2）130円　（3）550円

問題の要約: A を5個、B を3個買うつもりで計算した 5050 円は、単価を逆にしていた。実際の合計は 4790 円。A＋B、差、A の値段を求める。

表向きの分野: 買い物の文章題

実際に効いている見方: 個数と単価が入れ替わった2本の式を、和と差で処理する問題

構造的な急所: 『金額を逆にして計算した』ので、係数が 5 と 3 で入れ替わる

一言でいう勝ち筋: 3A＋5B と 5A＋3B の2式を『足す・引く』だけで処理する。

1. 解く前の観察タイム

  1. 『逆にして計算した』は、係数が入れ替わった2本の式が立つ合図です。
  2. 3A＋5B=5050、5A＋3B=4790 と読めるので、和と差が効きます。
  3. 係数の和がどちらも 8 なので、まず足すと A＋B が一気に出ます。
  4. その後は 2 個ぶん入れ替えたときの差で A と B の差が出ます。
  5. 表向きは方程式、本質は和差算です。

2. 初見での観察の順番

  1. 入れ替えた2本の式を書く: 何が逆になったかを固定するため。
  2. 2式を足して A＋B を出す: 係数がそろっていて最も自然。
  3. 2式を引いて差を出す: （2）（3）へつながる。

3. 入口候補

候補A：和差で処理

  • 何を見て立つ候補か: 3 と 5 が左右で入れ替わっている。
  • 最初に試す操作: 3A＋5B=5050、5A＋3B=4790 を足す。
  • うまくいくサイン: A＋B がすぐ出る。
  • うまくいかないサイン: 和差を使わないと計算が重くなる。
  • この候補の位置づけ: 係数の対称性を最も自然に使える。

候補B：連立方程式として解く

  • 何を見て立つ候補か: 2本の一次式がある。
  • 最初に試す操作: 片方を2倍して消去する。
  • うまくいくサイン: 確実。
  • うまくいかないサイン: この問題のよさである『入れ替えの対称性』が見えにくい。
  • この候補の位置づけ: 機械的には解けるが、入口としては重い。

4. 小実験

  • 小実験は『A を2個だけ B に交換したら何円変わるか』を見ることです。
  • 5050−4790=260 円は、A と B を2個ずつ交換した差に当たります。
  • よって 1 個分の差は 130 円とすぐに読めます。

逆から考える○A＋B が出た後に 2A を戻す。A の値段へ自然に着地できる。

  • A＋B が出たら勝ち筋です。あとは差130を合わせるだけです。
  • 式が増えたら『足すと8(A＋B)』『引くと2(B−A)』へ戻ります。

ステップ何をしているかなぜ自然か

  • この候補の位置づけ: 問題の本質に合う。

候補B：人数の流れだけ先に決める

  • 何を見て立つ候補か: B駅、C駅での乗降条件が細かい。
  • 最初に試す操作: 各駅後の乗客数をまず求める。
  • うまくいくサイン: （2）が軽くなる。
  • うまくいかないサイン: 最終的には区間分解が必要。
  • この候補の位置づけ: 候補Aの前処理として有効。

4. 小実験

  • （2）の小実験は、C駅で乗った人数を x 人と置くことです。
  • 降りた人数は 2.5x で差が 33 なので、x=22、降りた人数55 がすぐ出ます。ここから B駅後の人数 127 まで一気に戻れます。

5. 困ったときの6つの武器

6. 見切りと切り替え

  • 人数の流れが決まったら、あとは区間別に分けるだけです。
  • 運賃を先に掛け始めると混乱するので、必ず最後に金額へ移ります。

7. 解答解説の詳細分解

ステップ何をしているかなぜ自然か
第1手（1）は人数の流れを読む。Aから100人乗り、Bで15人降りるので A→D は85人、A→B は15人。Cで20人乗るので C→D は20人。合計は 600×85+200×15+400×20=62000円。
第2手（2）は C 駅条件から。乗った人数を22人、降りた人数を55人と出す。Dで94人降りるので C 駅後は94人、B駅後は127人。
第3手B駅の乗降を決める。100人から127人になり、『乗った人数は降りた人数の4倍』なので、降りた9人・乗った36人。
第4手区間別人数に分けて運賃を計算する。Cで降りた55人のうち、Aから乗った人はBから乗った人より21人多いので、A→C=38、B→C=17。残りは A→D=53、B→D=19、C→D=22。合計 71820 円。
第5手（3）は区間別人数を文字で置く。B→D と A→C が同じ人数になることなどを使って整理すると、合計運賃 64390 円から A→C=13 人。

8. 別解と多面的理解

（3）は解説のように面積図で処理してもよく、代数的には A→C を t とおくと総額が 64000+30t になって t=13 と出ます。

9. 誤答・失敗データ

  • その時点の乗客数だけで運賃まで計算しようとする。
  • 区間人数に分けず、Aから乗った人・Bから乗った人を混ぜてしまう。
  • （3）で人数条件を整理せず、いきなり金額の6変数に入る。
