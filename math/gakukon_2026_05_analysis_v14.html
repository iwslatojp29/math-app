第1問　23でしぼる買い物の整数問題

問題文問題のテーマポイント
太郎さんは、家の近くのコンビニへ消しゴムを買いに行きました。 消しゴムは 小・中・大・特大 の4種類があり、1個あたりの値段はこの順に 92円, 125円, 161円, 207円 です。 4種類の消しゴムをどれも1個以上買ったら 6000円 でした。 (1) 6000÷23 を筆算したときの余りを求めなさい。 (2) 中の消しゴムは何個買ったと考えられますか。考えられる個数をすべて答えなさい。 (3) 特大の消しゴムは最も多い場合で何個買ったと考えられますか。

PDF問題文をOCRテキスト化

  • 表向き：整数の文章題、場合の数。
  • 実際：値段を23で見直し、中の125円だけを浮かび上がらせる見方です。
92円・161円・207円は23で割り切れ、125円だけが23で割ると10あまること。ここから中の個数を先にしぼれます。

1. 問題文の読み方と初見の時の試し方

どこに注目するか？なぜ注目するか・どうしたら気づけるか？まず試す方針
最強条件・不自然条件3つの値段が23の倍数で、1つだけちがうのが最強条件です。こういう「1つだけ残る」形は、難問でいちばん先に疑いたい形です。23で割ったあまりだけを見ると、125円の個数だけが式に残る形にする。
数字・配置・端の意味「各1個以上」と「特大を最も多く」が後半のしぼりに効きます。前者で個数の上限が決まり、後者で特大を上から試せます。中の個数は多くても44個までと見て、候補を有限個にする。特大は理論上の上限から下げて調べる。
条件をどのように翻訳するか金額のまま4つを同時に追うと重いので、「23で割ったあまり」と「残りの金額」の2段階に分けると整理しやすくなります。まず「23で割ったあまりの表」に直し、そのあと候補ごとに残りの金額の式へ戻す。

2. 最初に書く図・表・式

  • 入口 ：23で割ったあまりで中の個数を先にしぼる。
  • 最初に紙に書くこと ：小・中・大・特大の個数を a,b,c,d として 92a+125b+161c+207d=6000、a,b,c,d は1以上と置く。その下に、92円・161円・207円は23で割り切れ、125円は23で割ると10あまると書く。

3. 解答解説

方針とその理由解答解説
第1手
まず (1) を処理して、23の感覚を作る。
  • まず合計を23で見たときのあまりを確かめる。
  • あとで125円だけが残る形になるので、ここが土台になる。
6000 = 23×260 + 20 → 23で割ると 20 あまる
第2手
本体の式を23で割る。
  • 3つが23で割り切れて、125円だけが残るのが急所。
  • あまりだけを見ると、中の個数だけに話をしぼれる。
92円、161円、207円は23で割り切れる。 125円は23で割ると10あまる。 だから、中の個数を b 個とすると 10×b を23で割ったあまりが 20 になる。 10を7倍すると 70 で、23で割ると 1 あまる。 そこで両方を7倍すると、b を23で割ったあまりは 20×7=140 を23で割ったあまりと同じ。 140 = 23×6 + 2 だから、b は23で割ると 2 あまる。 125×48=6000 をこえるので、中は44個まで。 したがって b は 2個 または 25個。
第3手
b=2 と b=25 をそれぞれ確かめる。
  • 候補は 2個 と 25個 の2本だけなので、1本ずつ確かめればよい。
  • 最大個数を聞かれているので、特大は上から試す。
中が2個のとき 92a+161c+207d=5750 特大を多くしたいので、まず d を大きい方から試す。 207×26=5382 なので、残りは 368。 368は 92×4 だから、大が1個も入らずだめ。 次に d=25 とすると、残りは 575。 575 = 92×1 + 161×3 だから、(a,c,d)=(1,3,25)。 中が25個のとき 92a+161c+207d=2875 たとえば (a,c,d)=(3,2,11) で 2875 になる。 だから 25個 も実際に買える。
第4手
答えをまとめる。
  • 小問ごとの答えを書き分ける。
  • (2) は 2個 と 25個 の両方を書く。
(1) 20 (2) 中は 2個、25個 (3) 特大は最大 25個

第2問　回転する正方形の軌跡と面積

問題文問題のテーマポイント
1辺4cmの正方形を、90°ずつ回す図形の問題です。 (1) 図1で、対角線 PR が90°回転するときに通る部分の面積を求めなさい。 (2) 図2で、1辺12cmの正方形の内側を同じように転がすとき、頂点 P の軌跡を図示しなさい。 (3) 図3の灰色の 4cm×4cm の正方形の中で、2本の円弧が作る「Xだけに入る部分」と「Yだけに入る部分」の面積の差を求めなさい。 円周率は3.14とします。

  • 表向き：図形、回転、軌跡、面積。
  • 実際：「動くものは何か」を決め、線分なら扇形、頂点なら円弧のつなぎ合わせとして見ることです。
Pの軌跡は1本の円ではなく、回転の中心が順番に移るので複数の1/4円弧の連結になることです。

最強条件・不自然条件(2) の軌跡は1本の円ではなく、中心が変わるたびに別の円弧になるからです。
  • まずは 座標を置いて円弧として追う。
  • B=(0,0), C=(12,0), D=(12,12), A=(0,12) と置く。
数字・配置・端の意味どの点で折れ、どの点が止まるかを方眼で読むのが安いからです。

Pの位置を (0,4)→(8,4)→(12,0)… と書き出す。

条件をどのように翻訳するか最後は16cm²の中で2本の曲線が4分割する問題だから、局所化すると楽です。
  • X=(4,12), Y=(8,8) と置いて、関係する2本の円弧だけを残す。

  • 最初に紙に書くこと: 大きい正方形を 4cm 方眼の 3×3 と見て、 B=(0,0), C=(12,0), D=(12,12), A=(0,12) と置きます。最初のPは (0,4) です。

3. 解答解説

方針とその理由解答解説
第1手
(1) は対角線PRを1本の線分として見る。

第2手
(2) はPの位置と回転の中心を順番に書く。
  • 各回転ではPは中心から一定距離なので1/4円弧になるからです。
  • ここでは「小正方形の1辺が4cm、大正方形の1辺が12cm」という条件を使う。
Pの要点: (0,4) → (8,4) → (12,0) → (8,4) → (8,12) → (4,8) → (0,4) 動く円弧の中心: (4,0), (8,0), (12,4), (12,8), (4,12), (0,8)
第3手

  • 灰色の正方形の中では、この2本の円弧だけが面積を切っているからです。
  • ここでは「図3の灰色部分は 4cm×4cm」という条件を使う。
X = (4,12), Y = (8,8) 赤い円弧: 中心X、半径4 青い円弧: 中心(12,8)、半径4√2
第4手
赤い円弧の内側の面積A、青い円弧の内側の面積Bを出す。
  • 差だけなら、AとBの合計から正方形16を引けばよいからです。
  • ここでは「青い円弧は 45° 分だけ灰色正方形に入る」という条件を使う。
A = 半径4の1/4円 = 4π = 12.56 B = 半径4√2、角45°の扇形 - 二等辺直角三角形 = π×(4√2)²×45/360 - 4×4÷2 = 4π - 8 = 4.56

最後の差を出して答えをまとめる。
  • 4つの部分を一つずつ求めなくてすむ最短ルートです。
  • ここでは「灰色正方形の面積は 16」という条件を使う。
差 = A + B - 16 = 12.56 + 4.56 - 16 = 1.12

1. 問題文の読み方と初見の時の試し方

どこに注目するか？なぜ注目するか・どうしたら気づけるか？まず試す方針

  • AC=Ht、BC=Tt、しかも BC=6H と置く。
数字・配置・端の意味休憩の6分が、花子さんの「CからBまで6分」ときれいに対応するからです。

  • H+T=J-H が出たら代入する準備をする。
  • 考えやすい形に直すと「J=T+126 を最後にはめる」になる。

2. 最初に書く図・表・式

  • 入り口 ：t分後にCで会う
  • 最初に紙に書くこと: 花子さんの速さを H 、太郎さんを T 、次郎さんを J 、Cですれ違うまでの時間を t 分と置きます。
使う算数の道具：一直線の線分図。A──C──B と置き、「会うまで」と「会ってから」を色分けして書く。

3. 解答解説

方針とその理由解答解説
第1手
Cですれ違うまでの関係を書く。
  • 出会い算では「同じ時刻まで進んだ距離」をそろえるのが基本だからです。
  • ここでは「花子さんと太郎さんは同時に出発し、Cで会う」という条件を使う。
AC = Ht BC = Tt AC + BC = 819 よって 819 = (H+T)t
第2手
花子さんの「会ってから6分」を使う。
  • 6分という具体時間は、区間BCを固定する強い条件だからです。
  • ここでは「Cですれ違ってから6分後にB着」という条件を使う。
花子さんは C→B を 6分で進む → BC = 6H BC = Tt でもあるから Tt = 6H
第3手
次郎さんの同時到着条件を使う。
  • 休憩6分が両辺で打ち消し合い、きれいな式になるからです。
  • ここでは「次郎さんはAで6分休み、花子さんと同時にBへ着く」という条件を使う。
花子さんのB到着は t+6 分後 次郎さんは C→A に AC/J = Ht/J 分 休憩 6 分 A→B に 819/J 分 同時到着より Ht/J + 6 + 819/J = t + 6 → Ht + 819 = Jt → 819 = (J-H)t
第4手
速さを解く。
  • 同じ819に掛かる時間 t が共通なので、速さ部分だけを比べられます。
  • ここでは「J=T+126」という条件を使う。
819 = (H+T)t = (J-H)t → H+T = J-H J = T + 126 だから H + T = T + 126 - H 2H = 126 H = 63 BC = 6H = 378 AC = 819-378 = 441 t = AC/H = 441/63 = 7 T = BC/t = 378/7 = 54

4. 別解

方針とその理由：一直線の線分図を描き、区間 BC と AC を文字で置く。時間 t を先に置かず、区間から速さへ戻す別解です。

最初に紙に書くこと：A──C──B の線分図を描き、AC を a m、BC を b m とおく。a+b=819。

方針とその理由解答解説
第1手
BC を花子さんの6分と結びつける。
  • 花子さんは C から B を6分で進むので、b=6H。
  • 太郎さんは会うまでに BC を進む。
BC=b=6H 太郎さんの会うまでの時間 = b/T
第2手
会うまでの時間を AC でも表す。
  • 花子さんは会うまでに AC=a を進む。
  • したがって a/H = b/T。
a/H = b/T → aT=bH
第3手
次郎さんの往復と同時到着で式を閉じる。
  • 次郎さんの移動距離は a+819、休けい6分つき。
  • これが花子さんの全時間 a/H+6 と等しい。
(a+819)/J + 6 = a/H + 6 → (a+819)/J = a/H J-T=126 と合わせて H, T を出す

転移テスト問題

＋ 解答解説を見る

同じ構造の理由

  • 「会うまでの同じ時間」と「同時到着の同じ全時間」を2本の式にする構造が同じです。

解答解説

  1. 会うまでを t 分とおくと、600=(H+T)t。
  2. 花子さんは C から B を4分で進むので BC=4H。これが太郎さんの BC=Tt と等しい。
  3. 次郎さんの全時間は AC/J + 4 + 600/J、これが花子さんの t+4 と等しい。
  4. J-T=100 と合わせて H,T を求める。

第4問　しきい値つき増減の周期

問題文問題のテーマポイント
底面積が 1000cm²、高さが 70cm の直方体の水そうに、高さ 8cm まで水が入っています。 1分ごとに、水の高さが 14cm 未満なら xL の水を入れ、14cm以上なら yL の水を出すことを繰り返します。 ただし、水そうから水があふれる場合や、水がなくなってしまう場合は考えません。 x,y の組が (4,6) のとき、8cmから始めて1分ごとの水の高さは 8,12,10,14,8,12,… と変化し、5分後に初めて8cmに戻ります。 (1) (x,y)=(2,7) のとき、および (8,10) のとき、初めて高さ8cmに戻るのは何分後ですか。 (2) 10分後に初めて高さ8cmに戻る整数の組 (x,y) について、 (ア) 考えられる x:y の最も簡単な整数比を4通り答えなさい。 (イ) 条件を満たす整数の組を8通り答えなさい。

PDF問題文をOCRテキスト化

  • 表向き：規則性、整数、場合分け。
  • 実際：水位を「14cmからのずれ」で見て、1回ごとに +x ずつ進む巡回としてとらえる見方です。
14cmを境に増減の向きが変わるので、14cmからのずれを並べると規則が一つにまとまります。誌面解説のよいところは、最初の数分を実際に書いて周期感をつかむ点です。

1. 問題文の読み方と初見の時の試し方

どこに注目するか？なぜ注目するか・どうしたら気づけるか？まず試す方針
最強条件・不自然条件「14cm未満なら入れる、14cm以上なら出す」という切り替え条件が最強です。こういう問題は、切り替えの線を0に置き直すと整理しやすくなります。14cmを0として、下にいれば +x、上にいれば -y と見る。
数字・配置・端の意味8cmから始めて8cmに戻るには、直前に 8+y cm まで上がっていなければいけません。ここから y は少なくとも 6 と分かります。「戻る直前の高さ」に注目して、y が6以上でないと戻れないことを先に書く。
条件をどのように翻訳するか毎分の高さそのものより、「14cmからのずれ」を並べた方が、何分で元に戻るかが見えやすいです。(4,6) など小さい例でずれの並びを書き、同じ並びに戻るまでの回数を見てから一般化する。

2. 最初に書く図・表・式

  • 入口 ：14cmからのずれを追って、同じ並びに戻る回数を見る。
  • 最初に紙に書くこと ：高さを h cm、14cmからのずれを d=h-14 と置く。8cmスタートなので最初は d=-6。下にいれば +x、上にいれば -y と書く。
使う算数の道具：高さの表。8cm,12cm,10cm,… のように最初の数分を実際に並べてから規則を見る。

3. 解答解説

方針とその理由解答解説
第1手
まず、Lをcmに直す。
  • Lの問題ではなく高さの問題に直す。
  • ここを直すと、あとが全部 cm でそろう。
底面積は1000cm²。 1Lは1000cm³だから、高さは1cm変わる。 よって、xL 入れると x cm 上がり、yL 出すと y cm 下がる。
第2手
14cmからのずれで表す。
  • 14cmを0にすると、切り替え条件が見やすい。
  • 「上に出たら1周ぶん戻る」形で考える。
d=h-14 とおく。 14cm未満なら d は x だけ増える。 14cm以上なら d は y だけ減る。 たとえば d=-6 から始めると、毎回 x ずつ進み、上にはみ出したぶんは x+y だけ引いて元の区間に戻る形になる。
第3手
(1)を確かめる。
  • 小問(1)は、実際に並べて確かめると安心。
  • 戻るまでの回数が両方とも9分だと見える。
(2,7) のとき -6, -4, -2, 0, -7, -5, -3, -1, 1, -6 → 9分で元に戻る (8,10) のとき -6, 2, -8, 0, -10, -2, 6, -4, 4, -6 → 9分で元に戻る
第4手
10分で初めて戻る比を出す。
  • 先に最も簡単な比へ落とすと、候補が一気に少なくなる。
  • 「初めて戻る」は、もっと短い周期がないことを表す。
x と y を、いっしょに割れるいちばん大きい数 g で割って x=gp、y=gq とする。 このとき p と q は互いにこれ以上いっしょに割れない。 同じ並びに戻るまでの回数は p+q 回になるので、 10分で初めて戻るなら p+q=10。 和が10で、互いにこれ以上いっしょに割れない正の整数の組は (1,9),(3,7),(7,3),(9,1)。 したがって比は x:y=1:9, 3:7, 7:3, 9:1。
第5手
実際にできる組だけを残す。
  • 比が合っても、実際に戻れない組は消す。
  • 戻る直前の高さと、あふれ・出しすぎを最後に確かめる。
1:9 → 8+y が14以上になるには y=9 だけ → (1,9) 3:7 → y は 7 または14 → (3,7),(6,14) 7:3 → y は6,9,12,15 → (14,6),(21,9),(28,12),(35,15) 9:1 → y は6だけ → (54,6)
